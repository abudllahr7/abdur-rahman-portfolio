FEATURED PROJECT / 01

IoT · SMART WASTE MANAGEMENT

ECO TRACK 2.0

Exploring how connected sensors and a web dashboard can help monitor waste conditions and support smarter waste management.

IN DEVELOPMENT
01 / THE PROBLEM

Understanding the challenge

Monitoring waste bins manually can take time and may not provide continuous information about their condition. Without timely updates, it can be difficult to identify when a bin needs attention.

02 / THE SOLUTION

A connected monitoring approach

ECO TRACK 2.0 is being developed as an IoT-based monitoring system. Sensors connected to an ESP32 collect information that can be displayed through a web dashboard.

03 / THE GOAL

Make monitoring easier

The project aims to make waste-bin information easier to view, understand and monitor through a central digital interface.

04 / MY LEARNING

Hardware meets software

This project helps me explore sensor integration, ESP32 development, backend APIs and dashboard development while improving my practical problem-solving skills.

TECHNOLOGY STACK

ESP32 HC-SR04 IR Sensor Water Sensor MQ135 HTML CSS JavaScript Node.js Express

SYSTEM WORKFLOW

How the system is designed to work

01

Sensor Input

Sensors collect information about the bin and its surrounding conditions.

02

ESP32 Processing

The ESP32 reads sensor values and prepares the information for the monitoring system.

03

Backend Communication

The backend is designed to receive and handle sensor information through an API.

04

Web Dashboard

The dashboard presents monitoring information in a visual interface for easier understanding.

CURRENT STATUS

Building and improving

ECO TRACK 2.0 is an active development project. Hardware integration, backend communication and dashboard capabilities will be documented as implementation progresses.
